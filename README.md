# Scroll Car Animation

Next.js + Tailwind + GSAP (ScrollTrigger) + Lenis.

## Run
```
npm install
npm run dev
```
Open http://localhost:3000

## Deploy (GitHub Pages)
1. Push to the `main` branch of a GitHub repo.
2. Repo Settings > Pages > Source: **GitHub Actions**.
3. The workflow builds and publishes to `https://<username>.github.io/<repo>/`.

## Use your own car image
Put the PNG in `public/` and change `CAR_SRC` in `components/Hero.jsx`.
